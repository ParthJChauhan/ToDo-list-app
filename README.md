# To-Do List Application

A simple and interactive To-Do List application designed to make everyday task management easier. This project allows users to add tasks, keep track of their progress, and remove completed or unnecessary tasks through a clean and minimal interface.

## ✨ Features

- **Add Tasks:** Quickly add new tasks to your to-do list.
- **Mark as Completed:** Mark tasks as complete to keep track of your progress.
- **Delete Tasks:** Remove tasks that are completed or no longer needed.
- **Clean UI:** A simple, minimal, and user-friendly interface.
- **Interactive Experience:** Dynamic task management without refreshing the page.

## 🛠️ Technologies Used

- **HTML5** – For structuring the application.
- **CSS3** – For styling and creating the user interface.
- **JavaScript** – For implementing interactive functionality and task management.
